Pomodoro Timer

How to use使い方

Add to Home Screen — iPhone / iPad

  1. Open this page in Safari.
  2. Tap the Share button .
  3. Scroll down and choose Add to Home Screen.
  4. Tap Add. Launch it from the new icon to use it full screen.

Sound won’t play while the silent switch is on.

Add to Home Screen — Android

  1. Open this page in Chrome.
  2. Tap the menu at the top right.
  3. Choose Add to Home screen or Install app.
  4. Tap Install (or Add) to confirm.

Timer

  • Set — tap min / sec buttons to add time, or swipe a digit up/down. Digits carry over (59 sec → 1 min).
  • History — your last 20 durations. Tap one to load it. Scroll sideways for more.
  • Start / Pause — the large button. The screen turns dark while running.
  • Reset — clears the time to 00:00.
  • When time is up, a bell rings and the same duration is loaded again, ready to repeat.

ホーム画面に追加 — iPhone / iPad

  1. Safari でこのページを開く。
  2. 共有ボタン をタップ。
  3. 下にスクロールして ホーム画面に追加 を選ぶ。
  4. 追加 をタップ。追加されたアイコンから起動すると全画面で使えます。

消音スイッチがオンだと音は鳴りません。

ホーム画面に追加 — Android

  1. Chrome でこのページを開く。
  2. 右上の メニュー をタップ。
  3. ホーム画面に追加 または アプリをインストール を選ぶ。
  4. インストール（または 追加）をタップして確定。

タイマー

  • 時間の設定 — min／sec のボタンで時間を足すか、数字の桁を上下にスワイプ。上限を超えると上の桁に繰り上がります（59秒 → 1分）。
  • 履歴 — 直近20回分の時間。タップでその時間をセット。横にスライドで過去分を表示。
  • スタート／一時停止 — 大きなボタン。計測中は画面が黒くなります。
  • リセット — 00:00 に戻します。
  • 時間になるとベルが鳴り、同じ時間が再セットされるので、そのまま繰り返せます。
